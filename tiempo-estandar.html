⏱️ Calculadora de Tiempo Estándar

Calcula el tiempo normal y el tiempo estándar de una operación considerando el desempeño del trabajador y los suplementos.

El resultado aparecerá aquí.

📚 Fórmulas utilizadas

Tiempo normal:
Tiempo observado × (Calificación / 100)

Tiempo estándar:
Tiempo normal × (1 + Suplementos / 100)

El tiempo normal ajusta el tiempo observado de acuerdo con la calificación de desempeño. Después se agregan los suplementos para obtener el tiempo estándar.
